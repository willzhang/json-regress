# json-regress：面向 JSON 与机器学习输出的 MoonBit 回归断言库

> AI 辅助参考稿，2026-09-14。官方申报要求本人撰写，请理解并用自己的表述重写；不是可直接冒充本人独立撰写的成稿。已形成 10 个开发阶段正式提交；公开仓库、远程 CI 及包发布尚待落实。

**项目简介**：开发一个 MoonBit 回归测试库，在不改变业务字段严格比较的前提下，支持明确路径的易变字段忽略和数值容差。进一步面向机器学习迁移、重构后的固定输出检查，提供显式 shape/dtype/data 的数值数组适配，定位错误坐标并汇总全部超差元素。项目聚焦测试工具，不构建新的训练框架。

**三个使用场景**：

1. JSON 接口与实验结果回归：忽略请求编号等易变字段，对 loss 等数值设置容差，保留样本数、状态和数组顺序的严格检查；区分字段缺失与 null。
2. 世界模型一步预测回归：使用真实 MoonXi-net CPU 层构成固定的 Linear–ReLU–Linear 小型动力学示例，对固定 observation/action/latent state 的下一步输出进行校验。独立 Python 标量运算生成期望值；能识别潜在维度交换和单个 latent 超差。该模型未训练，不宣称具备完整世界模型能力。
3. 强化学习轨迹回归：规范化 observation/action/reward/next_observation 及 episode、step、terminated、truncated，检查时间对齐、观测连续性、重置边界与终止类型。用两段确定性小环境轨迹展示正确结果与动作错位、奖励符号等错误，不以回报值判断算法优劣。

**技术特色与边界**：复用标准 Json 类型；核心无第三方运行时依赖。提供 compare、assert_matches、稳定文本与结构化差异；数值数组严格校验形状和源 dtype 元信息，统一应用明确容差，错误展示截断不影响完整统计。拒绝非有限值和不支持的数值幅度，公开 Double 精度限制；不提供广播、自动转置、自动 dtype 转换或自动更新期望值。

**已有进度**：本地 Wasm、Native 各 54 项测试通过，另有 5 项真实 MoonXi CPU 集成测试通过。上游锁定提交和 MIT 许可证有记录，参考数据可重新生成并验证校验和。世界模型样例最大绝对误差约 `1.19e-8`，植入错误可定位。已有 README、可运行用例、Apache-2.0 许可证和 CI 配置；远程 CI 尚未运行。
