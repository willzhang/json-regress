## 已知边界

默认使用 Double 精度。数值比较拒绝绝对值大于等于 2^53 和非有限值；上游解析已经丢失的精度无法恢复。忽略路径不要求存在，忽略节点包括其缺失与整个子树。报告保留 Json 引用，调用期间不应修改输入。最大比较深度 128；未验证大文档性能。

本机通过 `scripts/moon-local.sh` 调用英文临时路径下的工具链，避免已观察到的中文工具链路径崩溃。工具链及运行命令见 [验证](VALIDATION.md)。
