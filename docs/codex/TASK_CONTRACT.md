# 任务契约模板

用于没有现成任务文件的非微小改动。只填写与当前任务有关的项；本地文档、Issue 或工作说明任选其一，不要求重复填写。

## 问题与基线

- 要解决的一个具体问题：
- 类型：core / numeric-array / integration / scenario / documentation
- 代码基线：提交 ID；没有提交时说明并记录相关文件或哈希
- 可运行入口、当前结果和失败样例：

## 契约与范围

- 输入：Json/shape/dtype/轴顺序/时间对齐/来源版本
- 输出：匹配、差异、无效输入的区别
- 数值规则：公式、参数来源、精度与非有限值行为
- 允许修改的模块和兼容性要求：
- 非目标：

## 验收证据

- 应通过输入：
- 应失败输入与预期定位：
- 独立参考值及其生成方法：
- 实际需要达到的验证类别：
- 命令、后端与环境；未运行项怎么呈现：
