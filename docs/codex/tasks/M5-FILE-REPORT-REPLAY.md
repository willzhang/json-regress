# M5 文件比较、检查点诊断与重放

2026-09-15 用户确认实施两项扩展。基线 0900883，原核心不变。

问题：用户无法直接比较文件；模型/轨迹差异缺少统一诊断与可携带的比较复现。
输入：原始基线/候选 JSON、版本 1 规则。模式 json/tensor/trajectory/checkpoints。
输出：版本 1 JSON 报告、文本摘要、0/1/2 退出码、含原始输入文本的单文件重放包。
边界：checking 为纯 MoonBit 包；Native CLI 是独立模块，官方 x/fs 只进入此模块。固定小模型与自建 RL 实际导出，独立 Python 算式参考；不训练、不改变默认容差、不新增 GPU。
检查点：有序唯一 id + episode_id/step/layer + tensor，来源元数据默认逐字段一致，显式声明比较变量。缺失、顺序/时间错位、来源不可比、shape/dtype、数值错误分开报告。
验证：规则严格解析；正常/数值/形状/畸形/未知字段/容差边界；外部工作目录 CLI 退出码与稳定报告；中间层、布局、时间错位、来源负例；移动重放包后独立进程重现；真实 MoonXi Native/Wasm 后端探测与实际导出比较。
成本：先完成通用入口，再检查点与导出；后端不兼容探索最多约 2 小时，明确未证实范围。远程发布、报名不在本次授权中。
