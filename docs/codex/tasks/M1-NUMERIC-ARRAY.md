# M1：数值数组回归校验

状态：IMPLEMENTED。2026-09-14 收尾时 numeric 含 17 项测试，Wasm / Native 全库各 54/54 通过。Git 署名待用户提供，当前以真实阶段快照保留开发进度，快照不计作提交。

## 问题

现有逐叶子路径容差要求调用者逐项列出向量元素，不能直接表达一个模型输出数组的形状与整体数值规则。

## 目标与范围

增加独立的数值数组适配能力，保留现有 `compare` 默认行为。优先放在 `numeric/`；具体 API 在实现前写入接口草案。输入采用明确的 shape、dtype 和行优先 data；支持从指定 JSON 子树读取。不要新增广播、隐式转置、自动 dtype 转换或张量运算引擎。

设计起点：空 shape 表示一个标量，元素数为 1；包含零维度的 shape 对应空 data；维度必须是合法非负整数，乘积检查溢出。执行者可根据兼容性证据调整这些初版选择，但要同步文档和测试。

数值规则沿用核心对称公式和已知幅度/精度边界。dtype 作为源数据元信息严格比对，不伪称恢复原始二进制表示。不同 shape 或元素数不符时先报告结构错误，不能只比较前面重叠的元素。

## 期望输出

区分无效输入、结构不匹配和数值超差。对合法输入返回总元素数、超差数量、最大绝对误差、有限数量的错误坐标及对应值；展示截断不改变总计或通过结论。错误样本上限应有明确默认值且文档化。

## 最小验收

- 通过：同形同 dtype；零容差完全相等；包含小幅且在容差内的误差。
- 失败：单元素超差、维度交换、同元素数但 shape 不同、dtype 不符、NaN/Infinity、非法 shape、元素数错误。
- 边界：标量、空数组、负值、零、阈值两侧、大幅度数值保护、错误报告截断。
- 验证调用方不能修改/放宽规则来隐藏错误；参考输出由明确算例独立给出。
- 更新生成接口、README；受影响代码的格式、check、build、Wasm 和 Native 测试通过。

## 交付与限制

交付实现、黑盒测试、可运行小例子和接口文档。不需要网络/GPU/模型训练。若引入新的数学规则才足以支持真实用例，先形成有依据的接口变更并测试，不把静默扩大数值范围混入本任务。
