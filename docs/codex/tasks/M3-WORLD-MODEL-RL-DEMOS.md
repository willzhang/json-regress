# M3：世界模型与强化学习展示

状态：PLANNED，两个场景均未实现。依赖 M1；尽量复用 M2 的实际模型/适配器，不要求再接两个大型框架。

## A：世界模型一步预测

目的：验证模型组件迁移或重构后，固定条件下的一步预测结构和数值仍符合预期。

输入记录 observation、action、初始 state、模型/权重版本及随机噪声；在确定性推断分支或固定噪声下产生 next-state 向量，可附 reward/continue 输出。若用小型合成动力学模型，名称和文档须标为“简化一步动力学示例”；不声称完成 Dreamer、生成视频或世界模型训练。

应通过：结构相同、允许范围内的数值偏差。应失败：潜在维度改变、轴顺序错误、一个坐标超差或非有限值。展示具体位置与摘要，而非只给总体均值。

验收：可运行命令、固定输入/独立参考、至少一个通过与两个不同失败样例、来源与限制说明。来自真实模型还是合成示例分别标明。

## B：强化学习短轨迹

目的：发现采样、回放或格式迁移中的契约错误，而非评价新算法的奖励是否更高。

明确定义规范化字段 episode_id、step、observation、action、reward、next_observation、terminated、truncated；可以对一个固定动作序列的简化环境生成短轨迹，也可合法适配真实环境导出。记录 observation 的时间含义，显式做框架映射。

应通过：忽略运行元信息、允许小的连续状态误差，同时严格保留动作和标志。应失败：动作偏移一个时间步、奖励符号反转、终止/截断字段丢失或被错误合并、episode 边界拼接错误。若检查时间连续性，必须依据已声明的轨迹定义，不假设所有框架记录方式一致。

terminated 与 truncated 在不同情形影响 bootstrapping；不要未经环境定义就把两者视为互斥，或合并后宣称语义等价。[Gymnasium 说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

验收：一个通过案例和能定位时间步的失败案例；报告数据与环境来源、确定性条件及不可外推结论。固定 seed 不保证跨设备/版本复现完整训练。

## 共用交付与边界

两个例子共用核心、数值数组规则和元信息格式。小型、可公开夹具与参考生成代码随示例保存；不下载大型数据、不训练新模型、不增加 GUI。若只完成合成例子，标记 FIXTURE_VERIFIED；它不能替代 M2 的真实第三方集成。

在 README 中分别说明“解决什么开发错误”“怎么运行”“通过/失败输出”“目前不能证明什么”。每个示例应快速在本地运行，不把训练耗时转嫁给评审者。
