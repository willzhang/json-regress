# 实施路线图

方向已由用户在 2026-09-14 确认：数值数组适配 + 一个真实 MoonBit 机器学习项目接入，世界模型与强化学习均作为展示场景。当前是项目文件准备阶段。

| 阶段 | 当前状态 | 可评审交付物 | 完成判据 |
|---|---|---|---|
| M0 JSON 原型 | 已完成本地验证 | 核心库、28 项测试、三个原型示例 | 已有 Wasm/Native 结果 |
| M1 数值数组 | 待实现 | 形状/dtype 校验、数组容差、坐标和误差摘要 | 正负例与边界测试通过，不改变原有默认语义 |
| M2 真实接入 | 待探查 | 一个锁定版本的 MoonBit ML 库、薄适配器、独立参考值 | 真实执行到本库的 CPU 最小链路通过，植入错误被抓住 |
| M3 两个展示 | 待实现 | 世界模型一步预测、RL 短轨迹示例与来源记录 | 两者分别有可复现的通过/失败演示，准确标明合成/真实来源 |
| M4 交付整理 | 待前序证据 | 公开仓库、包发布、CI 结果、验收材料 | 工程结果与官方提交条件分别满足 |

执行顺序：M1 为主要开发任务；M2 可先做兼容性探查以提前暴露环境风险，正式集成依赖 M1。M3 复用 M1/M2 数据和适配器。两个展示不必各接入一个新框架；至少一个真实 MoonBit ML 接入是独立且必须保留的目标。

## 本轮之后的首个任务

执行 [M1-NUMERIC-ARRAY](tasks/M1-NUMERIC-ARRAY.md)。随后按 [M2-REAL-INTEGRATION](tasks/M2-REAL-INTEGRATION.md) 验证一个实际外部项目。不要把准备好了 M2 文档记为完成集成。

## 实施边界

用户目标是少花人工时间获得收入。

首个外部候选的环境探查建议以 60 分钟为一个检查点；连续两种明确修复仍不能建立最小链路时，记录证据并切换备选。需要自改编译器、GPU 或大规模训练时停止该分支，继续能独立完成的 M1/M3 部分。两个候选均不可用时，报告真实集成未完成，不擅自取消目标或用合成样例替代。

不为提高“竞争性”追加训练框架、模型效果榜、服务平台或大量指标。按 9 月 23 日准备交付材料规划；赛事公开截止日为 9 月 24 日，正式安排与变化须向官方核实。[赛事入口](https://moonbitlang.github.io/Hackathon2026/)
